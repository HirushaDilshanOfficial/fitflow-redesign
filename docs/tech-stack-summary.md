# Technology Stack Summary

| Layer | Selected Technology | Reason |
|---|---|---|
| Mobile frontend | React Native + TypeScript | Fast cross-platform development for iOS and Android. |
| Web frontend | React + shared TypeScript modules | Flexible web experience with reusable logic. |
| Main backend | Node.js + NestJS | Structured APIs, WebSockets and maintainability. |
| AI service | Python + FastAPI | Strong fit for recommendation models and nutrition image analysis. |
| Database | PostgreSQL | Reliable relational data, transactions and reporting. |
| Cache / real-time | Redis + WebSockets | Fast repeated reads and real-time events. |
| Authentication | Auth0 | Managed login, MFA and role-based access. |
| On-device AI | TensorFlow Lite / ML Kit | Lower latency and less sensitive data transfer. |
