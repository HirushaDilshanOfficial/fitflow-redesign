# FitFlow Redesign

FitFlow is a cross-platform fitness application redesign prepared for **IT3060 – Human Computer Interaction, Lab 05**.

The redesign focuses on better personalisation, easier nutrition tracking, clearer progress information, and positive social accountability.

## Main Features
- AI-generated personalised workout plans
- Workout editing and rescheduling
- Progress dashboard and streak tracking
- Camera-based nutrition logging
- Private social challenges and community features
- Real-time notifications
- Secure authentication and role-based access

## Selected Technology Stack
| Layer | Technology |
|---|---|
| Mobile | React Native + TypeScript |
| Web | React + TypeScript |
| Backend | Node.js + NestJS |
| AI Service | Python + FastAPI |
| Database | PostgreSQL |
| Cache / Real-time | Redis + WebSockets |
| Authentication | Auth0 |
| On-device AI | TensorFlow Lite / ML Kit |
